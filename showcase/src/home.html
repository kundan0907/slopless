How it works.

For new work, slopless asks before it builds. For existing work, it starts from what you have.

  1. 1You ask

    Name the job: improve a screen, or build a page, deck or app. Add a link, file or brand colours if you have them.

  2. 2It interviews you

    A few questions, each with options A to D and one marked Recommended. “slopless quick” skips them; “you pick” accepts every recommendation.

  3. 3It builds and checks

    It builds in your stack, looks at the rendered result, and fixes problems such as overflow, low contrast and broken controls before showing you.

  4. 4It reports back

    A short report: your choices, what changed, and each wording change as before and after. It doubles as the PR description.

A sample question.

The options are written for your project. Reply with letters like 1A 2C, your own words, or “you pick” to accept every recommendation.

Pick a mode.

Name the mode in your request. If you don't, slopless chooses: Quick for existing work, Standard for new work.

Quick

Default for existing work

You have a page, screen or deck to improve.

A focused V2 with no interview. Up to three high-impact fixes, your content and working controls kept, and a check before and after.

Use slopless quick. Improve this page. Keep my content.

Standard

Default for new work

You are building something new, or redesigning.

Asks a few questions with options A to D and a recommended pick. Then it builds, checks and reports.

Use slopless. Build a website for my product. Interview me first.

Deep

The story is complex, the work is cinematic or 3D, or you want a detailed audit.

Standard, plus deeper exploration of direction, storytelling and motion.

Use slopless deep. A cinematic launch page for our new app.

Review

You want a critique, not changes.

Inspects the rendered result and reports findings. It never edits your files. Ask for one lens:

  • BolderMore scale contrast, one clear idea.
  • QuieterFewer competing effects.
  • DistillSimpler grouping and order.
  • HardenEmpty states, long text, keyboard.

What it fixes.

The usual giveaways of an AI-made interface, and what takes their place.

  • Violet gradient wallpaperOne palette chosen for your subject
  • Emoji standing in for iconsReal icons from one set
  • Tiny uppercase label above the headlineA headline that says it
  • Stock words like unlock and seamlessPlain, specific copy
  • A glow on everythingDepth only where it helps
  • The same default font everywhereA typeface chosen for the project

Real icons, fonts and assets.

Icons are real SVGs from five packs: Lucide, Phosphor, Tabler, Heroicons and Remix, fetched through Iconify and kept to one style. Fonts and photos come the same way, with their licences.

Install slopless.

Add the skill

Claude Code plugin: add the marketplace
/plugin marketplace add kundan0907/slopless
Then install
/plugin install slopless@slopless

Optional: open /plugin, then Marketplaces, then slopless, and turn on auto-update. New versions then arrive when a session starts.

Any agent that supports skills
npx skills add kundan0907/slopless

It asks which agent to install for. Needs Node.js 22.20 or newer.

Claude Code, by hand
git clone https://github.com/kundan0907/slopless
mkdir -p ~/.claude/skills
cp -r slopless/slopless ~/.claude/skills/
Codex and others, by hand
git clone https://github.com/kundan0907/slopless
mkdir -p ~/.agents/skills
cp -r slopless/slopless ~/.agents/skills/
