# Tells

A tell is a device that makes work read as generated. Most began as good ideas; they became tells by being produced by default, everywhere, without a reason. **Banned** = remove unless the brief or the user's memory explicitly chose it. **Warned** = needs a one-sentence reason. `scripts/slop-scan.mjs` detects the starred items.

## Wave 1 (2023–24)
| Tell | Status |
| --- | --- |
| Violet/indigo/purple→blue gradients on heroes, buttons, glows ★ | banned |
| Gradient-filled headline text ★ | banned |
| Glowing or gradient primary button ★ | banned |
| Soft grey shadow under every card | banned |
| Three identical feature cards, each with an icon in a rounded square | banned |
| Emoji as icons or bullets ★ | banned |
| Centred headline + subtitle + two buttons + screenshot below | warned |
| Inter/Roboto as display face ★ | warned |

## Structure
| Tell | Status |
| --- | --- |
| Headline over two lines | banned |
| Stock section order (hero, logos, features, testimonial, pricing, CTA) | warned |
| Every section the same layout family | banned |
| More than ~70% of text centred | warned |
| Same 12px radius on everything | warned |
| Invented social proof, logos, star rows, "10,000+ teams" | banned |
| A CSS box or icon where a real picture belongs | warned |

## Copy ★
Genre verbs and adjectives, slogan pairs, tricolons, "not just X", "Get started"/"Learn more", more than a few em dashes, lorem ipsum. See `copy.md`.

## Motion
Identical fade-up everywhere; a dozen staggered hero entrances; hover lift on every card; bounce easing; meaningless infinite loops; reveals that fail and leave blank bands; sequences too fast to talk over; motion that ignores reduced-motion.

## Glass, honestly
Glass is the most abused material and also a legitimate one. Banned as decoration on every surface; allowed when the user chose it as the material, on few surfaces, with the recipe in `motion.md` and evidence on opaque panels.

## Removal is not enough
A page with every tell removed and nothing in their place is an empty page with good manners, and that reads as generated too. The tells were filling the gap where an idea should be. Fill it with the idea (`direction.md`), scale, full real content, real pictures, and one live thing.
