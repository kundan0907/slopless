# Reference sites

A curated library for the interview's "reference feel" question and for studying a technique. Pick three that fit the brief and name what exactly to borrow. Learn the decision (pacing, type scale, interaction); never copy layout, copy, assets or brand. Open a site in the browser only when the user picks it or a technique needs study (`inspiration.md` → Researching a technique).
