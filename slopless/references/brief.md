# Brief

Write after the interview. It doubles as the handoff for another session or agent. Keep it to one screen.

```markdown
# <Project>: <deliverable> v<N>

## Story
After this, <audience> believes <claim> because <proof>.
Surface: <deck | web | app | graphic>, <length/size>, runs on <where>.
Hero object: <what travels>. Idea: On this <surface>, <subject thing> becomes <device>.
Live thing: <what the viewer can do/watch>.

## Content authority
Source: <path/URL>. Its words, numbers, order, links, notes and images win.
Must not change: <list>. Unproven claims shown as targets: <list>.

## Beats / sections
| # | Claim (what is said) | On screen | What changes | Proof |
|---|---|---|---|---|

## Direction
Palette: <name + tokens>. Strategy: <restrained | committed | drenched | full>.
Material: <…>. Type: <display> / <body>. Motion: <level>, signature move: <…>.
Loved references: <url — what exactly>. Rejected: <url — why>.

## Constraints
<single HTML offline | stack>, versions never overwritten (<path>/<name>-v<N>), sizes to verify, controls, performance budget.

## Done means
Built at <path>; previous version untouched; slop-scan clean; screenshots reviewed; content audit passes; report separates verified vs unproven.
```

For talks, also write a speaker script: one row per beat with Say / Click / If asked (sourced answers).
